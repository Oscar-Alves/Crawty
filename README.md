# Crawty 🏠

Um software web para capturar, catalogar e exibir um compilado de imóveis das imobiliárias de São João del Rei.

**[Visite o projeto ao vivo](https://crawty-8dlt.vercel.app)**

---

## 📋 Sobre o Projeto

Crawty é uma aplicação desenvolvida para facilitar a busca e visualização de imóveis em São João del Rei, coletando dados de diferentes imobiliárias e apresentando-os de forma organizada e acessível em um único local.

### Funcionalidades Principais
- 🔍 **Captura de Dados**: Coleta automática de imóveis de imobiliárias locais
- 📊 **Catalogação**: Organização estruturada de todos os imóveis capturados
- 🖥️ **Interface Web**: Exibição intuitiva e responsiva dos dados

## 🚀 Como Começar

### Pré-requisitos
- Python 3.8 ou superior
- Git

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/HomoGodzilla/Crawty.git
cd Crawty
```

2. Crie um ambiente virtual:
```bash
python -m venv venv
source venv/bin/activate  # No Windows: venv\Scripts\activate
```

3. Instale as dependências:
```bash
pip install -r requirements.txt
```

4. Execute o projeto:
```bash
python main.py
```
